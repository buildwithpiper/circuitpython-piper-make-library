# PiperBlocklyLibrary
CircuitPython Library to support block-coding using the RP Pico microcontroller

## Documentation
[https://make.playpiper.com/python_reference.html](https://make.playpiper.com/python_reference.html)

## Supported Modules
| Module | Connectivity | Address |
|--------|--------------|---------|
| Distance Sensor (PING) | Pulse Width | N/A |
| Temperature Sensor (MCP9808) | I<sup>2</sup>C | `0x18` |
| Color Sensor (TCS34725) | I<sup>2</sup>C | `0x29` |
| Heart Sensor | I<sup>2</sup>C | `0x5b` |
| Motion Sensor (MPU6050) | I<sup>2</sup>C | `0x69` |
| Motor Module | I<sup>2</sup>C | `0x0f` |
| Radio Module | I<sup>2</sup>C | `0x54` |
| Lightshow | SPI | N/A |
| Controller | SPI | N/A |
| Joystick | Analog | N/A |
